# 行列構造とファイルサイズ

Anima の学習では、**学習ネットワーク**の下の **構造プレビュー**から、現在の設定で構築するアダプタの行列を確認できます。入口には重みファイルの推定サイズも表示し、ランク・アルゴリズム・学習範囲を比較できます。

<!-- doc-anchor: overview -->
## 実際のモジュールを確認

![ComfyUI テーマでの LoKr 行列構造とファイルサイズの推定](../images/shape-preview.ja-JP.jpg)

プレビューは仮想テンソルで学習ネットワークを構築します。ベースモデルの重みの読み込みや学習の開始は行いません。現在は Anima の標準 LoRA / LoHa / LoKr と、LyCORIS の LoCon / LoHa / LoKr に対応しています。

| 表示項目 | 意味 |
| --- | --- |
| 入出力次元 | 元の層に入る特徴数と出る特徴数 |
| 保存する行列の形状 | アダプタが学習・保存するテンソル。ベースモデルの重み全体ではありません |
| Rank・Alpha・スケール | 入力欄の値そのものではなく、選択したモジュールが実際に使う値 |
| パラメータ数 | アダプタ内の学習可能な値の個数。設定の規模の比較に使えます |
| ファイルサイズ | 保存テンソル・精度・ファイル形式からの推定。学習時のメモリ使用量ではありません |

<!-- doc-anchor: file-size -->
## ファイルサイズの推定方法

アダプタが実際に保存するテンソルを指定の保存精度で数え、safetensors のテンソル索引ヘッダーを加えます。`fp16` / `bf16` は 1 要素 2 バイト、`float` は 4 バイトです。alpha などの学習対象外の保存テンソルも含むため、単純な「学習パラメータ数 × 要素のバイト数」とは異なります。

これは **LoRA 重みファイル**の推定です。ベースモデル・オプティマイザの状態・学習キャッシュ・サンプル画像は含みません。VRAM の推定でもありません。学習メタデータで容量が増え、他の保存形式では付加情報のサイズも異なる場合があります。最終的なファイルサイズが実際の値です。

比較する場合はアルゴリズムと範囲を固定してランクを変えるか、ランクを固定して範囲を変えます。LoKr は因子が低ランクから完全な行列へ切り替わると、サイズの増え方が変わります。設定変更ごとに形状と推定値を確認してください。

未対応の設定や構築の失敗では、推定エラーを表示します。
