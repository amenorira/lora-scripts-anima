# 行列構造とファイルサイズ

Anima または MOSS-Image の学習では、**学習ネットワーク**の下の **構造プレビュー**から、現在の設定で構築するアダプタの行列を確認できます。入口には重みファイルの推定サイズも表示し、ランク・アルゴリズム・学習範囲を比較できます。

<!-- doc-anchor: overview -->
## 実際のモジュールを確認

![ComfyUI テーマでの LoKr 行列構造とファイルサイズの推定](../images/shape-preview.ja-JP.jpg)

プレビューは仮想テンソルで学習ネットワークを構築します。ベースモデルの重みの読み込みや学習の開始は行いません。Anima と MOSS-Image のネイティブ LoRA / LoHa / LoKr、および Anima の LyCORIS LoCon / LoHa / LoKr に対応しています。

MOSS-Image の 3 つのネイティブ方式では、既定で 42 個のメインブロックの Attention と MLP 射影、計 252 個のアダプタモジュールを集計します。「テキスト投影層と Refiner を学習」を有効にすると、DiT 内のテキスト入力射影と 2 個の Refiner ブロックから 11 個のモジュールが加わります。凍結した Qwen テキストエンコーダは含みません。統合された QKV 射影や MLP の拡張・ゲート射影は、実際の統合行列の次元で表示します。LoHa は 2 組の低ランク積の要素積を表示します。LoKr は実際の factor と rank に基づく Kronecker 因子と、W2 の低ランク・完全行列のモードを表示します。ランクの上書きや除外パターンにより対象数は変わります。

| 表示項目 | 意味 |
| --- | --- |
| 入出力次元 | 元の層に入る特徴数と出る特徴数 |
| 保存する行列の形状 | アダプタが学習・保存するテンソル。ベースモデルの重み全体ではありません |
| Rank・Alpha・スケール | 入力欄の値そのものではなく、選択したモジュールが実際に使う値 |
| パラメータ数 | アダプタ内の学習可能な値の個数。設定の規模の比較に使えます |
| ファイルサイズ | 保存テンソル・精度・ファイル形式からの推定。学習時のメモリ使用量ではありません |

## ファイルサイズの推定方法

アダプタが実際に保存するテンソルを指定の保存精度で数え、safetensors のテンソル索引ヘッダーを加えます。`fp16` / `bf16` は 1 要素 2 バイト、`float` は 4 バイトです。alpha などの学習対象外の保存テンソルも含むため、単純な「学習パラメータ数 × 要素のバイト数」とは異なります。

見積もるのはアダプタの重みファイルだけです。ベースモデル、オプティマイザの状態、学習キャッシュ、プレビュー画像は含みません。現在は safetensors 形式で計算しています。学習メタデータや他の保存形式による付加情報もあるため、最終サイズは保存したファイルで確認してください。

比較する場合はアルゴリズムと範囲を固定してランクを変えるか、ランクを固定して範囲を変えます。LoKr は因子が低ランクから完全な行列へ切り替わると、サイズの増え方が変わります。設定変更ごとに形状と推定値を確認してください。

未対応の設定や構築の失敗では、推定エラーを表示します。
