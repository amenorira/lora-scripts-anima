# 训练集诊断

支持 **SDXL**、**Anima**、**MOSS-Image**（Krea 2 暂不记录 `loss.jsonl`）。

训练每一步都会为图片随机抽取噪声时间步，不同噪声强度下的原始 Loss 差距很大。某张图片可能只是碰巧多抽到了几次高 Loss 的时间步，平均 Loss 就会显得偏高，因此无法直接用原始 Loss 横向比较图片好坏。

本功能沿用 Kohya `sd-scripts` 的逐样本分析思路（详见上游文档 [`loss.jsonl` 与残差分析](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/docs/run_control.md#analyzing-the-loss-log--loss-%E3%83%AD%E3%82%B0%E3%81%AE%E5%88%86%E6%9E%90)），将每张图的采样放回**相近的时间步（噪声水平）**中对比，用两个指标定位问题：

- **残差（相对难易）**：单次 Loss 相比同时间步区间平均 Loss 的高低。`0%` 为全集平均水平；正值越大越难学，负值越小越容易。
- **每 Epoch 斜率（残差是否在下降）**：满 3 个可比较 Epoch 后，残差每轮相对同轮其他图片的变化速度。负值代表与全集均值的差距正在缩小，接近 `0%` 或为正代表停滞不降。

两个指标比较的都是**同一次训练内部**不同图片之间的相对表现；模型整体收敛质量仍需结合存档生成预览判断。

## 实际怎么看：状态与处理建议

Kohya 原版脚本仅按残差从高到低排序；本界面在此基础上按**最少采样**（默认 `≥ 3` 次可比较采样）、残差 `±20%` 与**下降斜率阈值**将图片自动归类。

下降斜率阈值按**该图实际参与拟合的首末可比较 Epoch 跨度**计算：跨度 `≤ 5`（即 `≤ 6` 个连续 Epoch）时为 **`-2.0% / Epoch`**；跨度在 `5 ~ 25` 之间按**该跨度内累计降幅 `≥ 10%`** 自动折算；跨度 `≥ 25` 时固定为 **`-0.4% / Epoch`**，避免长轮数训练把稳步下降的图片误判为停滞。这些阈值仅作为快速分档参考线，排查时可结合散点图离群位置或列表排序重点查看排名靠前的图片：

| 状态信号 | 判定条件（自上而下匹配） | 常见原因与建议操作 |
| --- | --- | --- |
| `NaN / Inf` | 出现非有限 Loss（最优先） | 个别图出现时检查文件损坏或异常色彩空间；大面积出现时检查学习率与混合精度 |
| `待统计` | 有效采样或同区间参照 `< 最少采样`（详情标为**采样不足 / 参照不足**） | 样本尚未积累够，可继续训练或临时调低顶栏**最少采样**查看 |
| `高残差待查` | 残差 `≥ +20%`，且未满 3 轮或斜率未达下降阈值（详情细分为**待查 / 未下降 / 下降慢**） | 长期高于均值且降不下来，常见于漏标错标、坏图、裁切不当或画风特征冲突。点开单图核对原图与标注，独立文本可点**在标签编辑器中打开**修改 |
| `高残差下降中` | 残差 `≥ +20%`，且斜率 `≤ 下降斜率阈值` | 构图或特征较复杂，但模型正在稳定吸收；保留图片继续观察 |
| `低于均值` | 残差 `≤ -20%` | 构图简单或集内存在近似重复图；若大批图片极低，结合生成预览留意过拟合 |
| `接近均值` | `-20% < 残差 < +20%` | 与训练集整体进度一致，无需额外处理 |

## 排查路径与常用设置

1. **先看总览定位是个别图问题还是整组偏差**
   - **左栏散点图**：未满 3 轮时按残差展开，满 3 轮后横轴为残差、纵轴为斜率。开启分区后，点击右上或右下色区可筛选全部「高残差待查」或「高残差下降中」图片。单图阈值不同时，两区之间留白，该范围内按圆点颜色区分状态。点击圆点可固定预览卡并进入单图详情。
   - **右栏分组对比**：按**数据集子集 / 文件夹 / 分桶尺寸 / 批次大小**汇总平均残差与斜率。若某一个子集、文件夹或分桶尺寸整体明显偏高，优先检查该组的重复次数（`num_repeats`）、标注习惯、长宽比裁切误差或子集时间步偏移；点击行末 **`↗`** 可切到逐图排查查看该组图片。
   - **右栏时间步区间（`1000 → 0`）**：按去噪顺序（左高噪、右低噪）展示 18 个区间的均 Loss、高/中/低噪采样占比与虚线理论分布。悬停或选中任意状态、分组、单图时，会在图上叠加对比曲线，方便看出偏高集中在哪个噪声段。
2. **进单图详情核对原图、分桶裁切与打标**
   - 左侧对照 `原图 → 分桶` 尺寸与裁切/放大比例，排查主体是否被裁掉或过度拉伸。
   - 右侧对照该图在各轮的残差走势、各时间步采样点相对于全集均值的偏离位置，以及当前生效的标注文本。
3. **顶栏范围与续训记录段**
   - **正则集范围**：含正则化图片时，默认**仅训练集**（避免正则图混入训练图的均值基准），可按需切换**仅正则集 / 全部数据集**。
   - **记录段**：同一输出目录与名称会向同一个 `loss.jsonl` 追加新记录段。**断点续训**时在顶栏**记录段**选**合并全部记录**以连续统计斜率；**同名重新从头训练**时保持默认的**最新**。

## 计算口径与上游差异

本训练器直接读取 `sd-scripts` `--run_control` 写入的 `loss.jsonl`，并在上游 [`tools/analyze_run_loss.py`](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/tools/analyze_run_loss.py) 的基础上做了以下分析增强：

- **残差基准（10 区间）**：按观测时间步范围划分为 10 个等宽区间，区间内至少含 **2 张不同图片**才构成参照（缺时间步或独处一区间仅计入均 Loss 与总采样数）：

<div class="doc-equation" role="group" aria-label="单次采样残差公式">
  <div class="doc-equation-kicker">单次采样残差</div>
  <div class="doc-equation-expression">残差 = 单次 Loss ÷ 所在时间步区间平均 Loss − 1</div>
  <p>图片或分组残差为所有可比较采样残差的均值（<code>0%</code> 为均值，正偏难学，负偏易学）。</p>
</div>

<!-- doc-anchor: slope -->
- **同轮同区间斜率**：计算每轮残差时，改以**同 Epoch、同时间步区间内其他图片的平均 Loss**（`> 0`）为参照，满 3 个 Epoch 后做最小二乘拟合，消除全局 Loss 下降对斜率的影响。
- **时间步权重还原**：`loss.jsonl` 中的 `loss` 包含 `--weighting_scheme`（参见[时间步](timesteps.zh-CN.md#weighting)）与 masked loss 权重，不含样本 `loss_weight`（如 `--prior_loss_weight`）与 `--min_snr_gamma`。在 **Anima** 与 **MOSS-Image** 下使用 `sigma_sqrt` 或 `cosmap` 时，诊断会先按时间步反除还原未加权 Loss 再统计残差。
- **落盘与多卡**：日志约每 5 秒随 `status.json` 刷盘；多卡训练仅记录主进程（rank 0）样本。完整日志字段说明见 Kohya 上游文档 [`run_control.md#lossjsonl`](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/docs/run_control.md#lossjsonl)。
