# 训练集诊断

支持 **SDXL**、**Anima**、**MOSS-Image**（Krea 2 / `musubi-tuner` 暂不输出 `loss.jsonl`）。

训练每步都会为样本随机抽取噪声时间步，不同噪声水平下的原始 Loss 天然相差数倍；单张图只要碰巧多抽中几次高噪或高损区间，原始均 Loss 就会虚高。诊断面板沿用 Kohya `sd-scripts` 的逐样本残差思路（参见上游 [`loss.jsonl` 与残差分析](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/docs/run_control.md#analyzing-the-loss-log--loss-%E3%83%AD%E3%82%B0%E3%81%AE%E5%88%86%E6%9E%90)），将每次采样放回**相近的时间步区间**内横向对比：

- **残差（相对难易度）**：单次 Loss 相对同时间步区间均值的偏离比例。`0%` 为全集均值；正值越大越难拟合，负值越小越容易拟合。
- **每 Epoch 斜率（残差是否在收敛）**：积累满 `3` 个可比较 Epoch 后，该图残差每轮相对同轮其他图片的变化速度。负值代表与全集均值的差距正在缩小，接近 `0%` 或为正代表停滞不降。

两项指标衡量的是**同一次训练内部**各图片的相对表现；模型整体画质仍需结合存档生成预览评估。

<a name="rules"></a>
## 状态信号与处理建议

界面综合**最少采样**（默认 `≥ 3` 次可比较采样）、残差 `±20%` 分界与动态**下降斜率阈值**将图片自上而下归入 6 类状态：

| 状态信号 | 判定条件（自上而下优先匹配） | 常见成因与建议操作 |
| --- | --- | --- |
| `NaN / Inf` | 记录到非有限 Loss | 仅个别图触发时排查文件损坏或异常色彩通道；大面积触发时立即检查学习率与混合精度 |
| `待统计` | 有效采样或同区间参照数 `< 最少采样`（详情标为**采样不足 / 参照不足**） | 样本尚未攒够，继续训练数轮或临时调低顶栏**最少采样**查看初步分布 |
| `高残差待查` | 残差 `≥ +20%`，且未满 3 轮或斜率未达下降阈值（详情细分为**待查 / 未下降 / 下降慢**） | 持续高于均值且不收敛，常见于漏标错标、坏图、主体被裁切或画风特征冲突。点开单图核对原图与打标，独立文本可点**在标签编辑器中打开**直接修正 |
| `高残差下降中` | 残差 `≥ +20%`，且斜率 `≤ 下降斜率阈值` | 构图、透视或服饰细节较复杂，但模型正在稳步吸收；保留原图继续观察 |
| `低于均值` | 残差 `≤ -20%` | 纯色简单构图或集内近似重复图；若大批图片极低，结合预览图排查过拟合或削减重复样本 |
| `接近均值` | `-20% < 残差 < +20%` | 与数据集整体进度一致，无需额外处理 |

注：下降斜率阈值会根据每张图实际跨过的可比较 Epoch 跨度在 `-2.0% ~ -0.4% / Epoch` 之间自动折算（公式见下方[同轮同区间斜率](#slope)），排查时可结合散点图离群点与列表排序优先检视最突出的样本。

<a name="workflow"></a>
## 排查路径与面板联动

1. **先在「诊断总览」区分个别坏图与整组偏差**
   - **左栏散点图**：满 3 轮前展示一维残差分布，满 3 轮后切换为**残差 × 斜率**二维散点图。打开右上角**区域着色**开关后，点击右上或右下色区即可一键筛选全部「高残差待查」或「高残差下降中」图片（各图跨度阈值不同时两区之间留有过渡带，按圆点颜色区分状态）；点击任意圆点可固定预览卡并进入单图详情。
   - **右栏 ① 图片状态分布**：汇总各状态图片数，点击任意状态行可联动过滤散点图与时间步曲线。
   - **右栏 ② 时间步区间（`1000 → 0`）**：按去噪推进顺序（左高噪 `1000`、右低噪 `0`）展示 18 个区间的均 Loss、高/中/低噪采样占比与虚线理论采样分布。悬停或选中状态、分组或单图时会叠加对比曲线，可根据偏高位置定向处理：
     - **左段高噪区（大构图与色块期）明显偏高**：多见于白底立绘与复杂背景混训、大幅补边或长宽比裁切跨度过大，优先补齐背景打标、检查分桶裁切或调整子集时间步偏移；
     - **右段低噪区（纹理与细节期）明显偏高**：多见于原图模糊、JPEG 压缩伪影、网点噪点或水印文字残留，优先替换或剔除低画质原图。
   - **右栏 ③ 分组对比**：按**数据集子集 / 文件夹 / 分桶尺寸 / 批次大小**汇总平均残差与斜率（当文件夹与子集完全一致，或某维度只有唯一分组时，对应标签会自动隐藏）。若整组明显偏高，优先检查该组的重复次数（`num_repeats`）、打标口径或分桶裁切；点击行可筛选诊断总览图表，点击行末 **`↗`** 直接跳转至**逐图排查**查看该组图片。
2. **进单图详情核对裁切比例与生效标注**
   - 左侧对照 `原图 → 分桶` 尺寸及裁切/缩放比例，确认关键主体未被裁掉或过度放大。
   - 右侧查看该图逐轮残差折线、各时间步采样点相对全集均值的偏离位置，以及当前生效的提示词文本。
3. **顶栏数据集范围与续训记录段**
   - **正则集范围**：存在正则化图片时默认选**仅训练集**，防止正则图拉偏训练图均值基准；可按需切换**仅正则集 / 全部数据集**。
   - **记录段**：复用相同输出目录与名称会向同一份 `loss.jsonl` 追加新段。**断点续训**时在顶栏**记录段**选**合并全部记录**以跨段连续拟合斜率；**同名从头重训**时保持默认的**最新**。

<a name="residual"></a>
## 计算口径与上游差异

本功能读取 `sd-scripts` `--run_control` 写入的 `loss.jsonl`，并在上游 [`tools/analyze_run_loss.py`](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/tools/analyze_run_loss.py) 基础上做了以下增强：

<a name="residual-bins"></a>
### 残差基准（10 等宽区间）

将观测到的时间步范围等分为 10 个区间，同一区间内至少有 **2 张不同图片**才构成有效参照（缺失时间步或独自落入某区间的采样仅计入均 Loss 与总采样数）：

<div class="doc-equation" role="group" aria-label="单次采样残差公式">
  <div class="doc-equation-kicker">单次采样残差</div>
  <div class="doc-equation-expression">残差 = 单次 Loss ÷ 所在时间步区间平均 Loss − 1</div>
  <p>单图或分组残差为全部可比较采样残差的算术均值（<code>0%</code> 为均值，正偏难学，负偏易学）。</p>
</div>

<a name="slope"></a>
### 同轮同区间斜率与跨度阈值

计算逐轮残差时，改以**同一 Epoch、同一时间步区间内其他图片的平均 Loss**（`> 0`）为基准，满 3 个可比较 Epoch 后做最小二乘线性拟合，剥离全局 Loss 自然下降对斜率的干扰。

判定「高残差下降中」所用的**下降斜率阈值**按该图首末可比较 Epoch 的跨度（`span`）分段计算：

- 跨度 `≤ 5`（即 `≤ 6` 个连续 Epoch）：固定为 **`-2.0% / Epoch`**；
- 跨度 `5 ~ 25`：按该跨度内**累计降幅 `≥ 10%`** 自动折算（即 `-10% / span`）；
- 跨度 `≥ 25`：固定下限为 **`-0.4% / Epoch`**，避免长轮数训练把稳步缓慢收敛的样本误判为停滞。

<a name="timestep-deweighting"></a>
### 时间步权重还原与日志刷盘

- **时间步去权**：`loss.jsonl` 记录的 `loss` 含有 `--weighting_scheme`（见[时间步](timesteps.zh-CN.md#weighting)）和蒙版权重，不含样本 `loss_weight`（如 `--prior_loss_weight`）与 `--min_snr_gamma`。在 **Anima** 与 **MOSS-Image** 下启用 `sigma_sqrt` 或 `cosmap` 时，诊断会先按对应时间步反除权重还原未加权 Loss，再统计区间均值与残差。
- **刷盘与多卡限制**：日志约每 5 秒随 `status.json` 同步落盘；多卡训练仅记录主进程（rank 0）抽到的样本。完整字段定义见上游 [`run_control.md#lossjsonl`](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/docs/run_control.md#lossjsonl)。
