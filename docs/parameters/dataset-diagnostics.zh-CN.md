# 训练集诊断

支持 **SDXL**、**Anima**、**MOSS-Image**（Krea 2 / `musubi-tuner` 暂不输出 `loss.jsonl`）。

训练每步都会为样本随机抽取噪声时间步，不同噪声水平下的原始 Loss 天然相差数倍。诊断面板沿用 Kohya `sd-scripts` 的逐样本残差思路（参见上游 [`loss.jsonl` 与残差分析](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/docs/run_control.md#analyzing-the-loss-log--loss-%E3%83%AD%E3%82%B0%E3%81%AE%E5%88%86%E6%9E%90)），将每次采样归入**对应的时间步区间**内横向对比：

| 核心指标 | 含义 | 读数参考 |
| --- | --- | --- |
| **残差** | 单次 Loss 相对同时间步区间平均 Loss 的偏离比例 | `0%` 为全集均值；正值偏难学，负值偏易学 |
| **每 Epoch 斜率** | 满 `3` 个可比较 Epoch 后，相对同轮其他图片基准的残差每轮变化速度 | 负值表示差距正在缩小；接近 `0%` 表示趋平，正值表示残差上升（差距拉大） |

残差衡量的是同一次训练内部的相对偏离（全集加权平均恒为 `0%`）。例如一个 40 张图的角色集里混有 30 张纯色半身立绘和 10 张复杂场景插画：

| 样本类型 | 早期平均 Loss（全集均值 `0.178`） | 第 8 轮平均 Loss（全集均值 `0.143`） | 变化说明 |
| --- | --- | --- | --- |
| 纯色半身立绘（30 张） | `0.15`（残差 `-15.5%`） | `0.12`（残差 `-15.8%`） | Loss 降约 20%，相对位置不变 |
| 复杂场景插画（10 张） | `0.26`（残差 `+46.5%`） | `0.21`（残差 `+47.4%`） | 同样降约 20%，但残差一直偏高、斜率接近 `0%` |

> 残差与斜率仅反映同一次训练内部各图的相对表现；判断整体画质是否达标或是否过拟合，仍需结合存档生成预览图。

<a name="rules"></a>
## 状态信号与判定条件

界面按优先顺序结合**最少采样**（默认 `≥ 3` 次可比较采样）、残差 `±20%` 分界与动态**下降斜率阈值**将图片归入 6 类状态（状态栏与筛选栏按下列顺序展示）：

| 状态信号 | 判定条件 | 初步方向 |
| --- | --- | --- |
| `NaN / Inf` | 记录到非有限 Loss | 仅个别图触发时排查文件损坏或异常色彩通道；大面积触发立即检查学习率与混合精度 |
| `高残差（不下降）` | 残差 `≥ +20%`，且未满 3 个可比较 Epoch 或斜率未达下降阈值 | 只要任意图片满 3 个可比较 Epoch，总览分类即切为此名称；其中仍未满 3 轮的图在单图详情标为**高残差**，有斜率但未达标时细分为**高残差（下降慢）**（`< 0`）或**高残差（不下降）**（`≥ 0`）。结合下表核对原图、裁剪与标注 |
| `高残差（下降中）` | 残差 `≥ +20%`，且斜率 `≤ 下降斜率阈值` | 构图或细节较复杂且模型正在稳步吸收，保留原图继续观察 |
| `接近均值` | `-20% < 残差 < +20%` | 与数据集整体进度一致，无需额外处理 |
| `低残差` | 残差 `≤ -20%` | 常见于简单构图、接近底模画风或近似重复图；界面绿色仅表示相对更易拟合，大批图片集中偏低时需结合预览排查过拟合 |
| `待统计` | 有效采样数或可比较采样数 `< 最少采样`（详情标为**采样不足 / 参照不足**） | 采样次数尚未攒够，继续训练或临时调低顶栏**最少采样**查看初步分布 |

注：`NaN / Inf` 与 `待统计` 会优先于残差阈值进行判定；下降斜率阈值按每张图可比较 Epoch 跨度在 `-2.0% ~ -0.4% / Epoch` 之间自动折算（见下方[同轮同区间斜率](#slope)）。

<a name="diagnosis"></a>
## 高残差与低残差判读

### 高残差的 4 种常见情形

点开高残差单图，结合**斜率、时间步曲线（左高噪 / 右低噪）、裁剪比例与标注**判断处理方式：

| 常见情形与例子 | 面板特征 | 原因与处理 |
| --- | --- | --- |
| **标注遗漏或冲突**<br>画面里角色戴着显眼的红色眼镜、身旁还有第二个人，但 `.txt` 只写了 `1girl, solo`；或复杂场景图没写背景词 | 残差明显偏高（如 `+30% ~ +60%`），满 3 个可比较 Epoch 后斜率停滞或上升；时间步**左/中段（高噪构图与中噪结构区）**明显高于全集曲线 | 文本条件与画面内容矛盾，模型被迫拟合互相打架的监督信号。进单图详情核对标注，点**在标签编辑器中打开**补全或修正冲突标签 |
| **画质模糊、压缩噪点或水印**<br>低清小图硬放大、严重 JPEG 压缩块、漫画网点噪点、角落大段文字或水印 | 残差偏高且难降；时间步**右段低噪区（细节期，`t` 接近 `0`）**明显翘起，左段高噪区却接近均值 | 低噪阶段负责还原高频纹理，随机噪点和压缩块无规律可循，Loss 降不下去。替换清晰原图、裁除水印，或剔除低画质图 |
| **主体被分桶裁剪**<br>竖长全身图被分进接近方形的分桶，标注写着 `boots, standing`，实际裁剪后下半身不在画面内 | 详情页左侧 `原图 → 分桶` 裁剪比例偏大，或右栏**分桶尺寸**分组中某个比例整组偏高（顶部可能显示**裁剪误差**提示） | 标注描述的物体已被裁掉，等同于图文不匹配。放宽分桶长宽比限制或调小分桶步长、预先手动裁图，或删去被裁掉部位的标签 |
| **复杂构图 / 稀缺视角**<br>大透视仰拍、华丽服饰或盔甲、复杂光影插画，且这类图在集内占比较小 | 残差 `+20% ~ +40%`；满 3 个可比较 Epoch 后常呈**高残差（下降中）**，中后期随全集 Loss 同步下降而斜率趋平；原图清晰、裁剪正常、标注准确 | 画面固有信息量高于全集平均水平，或该构图出现频次低。**保留原图**；若希望模型更充分掌握这类构图，可适度补充同类图或提高该子集 `num_repeats` |

### 低残差的 3 种常见情形

| 常见情形与例子 | 面板特征 | 原因与处理 |
| --- | --- | --- |
| **简单 / 纯色构图**<br>白底三视图、大面积纯色天空、强背景虚化的大头特写 | 仅少数极简构图落入低残差，其余大部分图片仍围绕 `0%` 分布 | 大块平滑区域缺少高频细节，在任意噪声水平下都容易预测，Loss 天然偏低。属于正常现象，无需处理 |
| **近似重复图或重复次数过高**<br>同一姿势连拍 6 张、立绘 5 张表情差分（底图大部分像素一致），或某子集 `num_repeats` 远高于其他子集 | 残差迅速跌至 `-30% ~ -50%`，同时把其余正常图相对顶高 | 模型很快直接记住固定像素，容易导致出图僵硬、换构图崩坏。削减重复样本或下调对应子集 `num_repeats`，并结合预览图检查泛化能力 |
| **接近底模默认画风**<br>在二次元底模上训画风 LoRA 时，集内混入大量接近底模原画风的标准正面特写 | 大批图片偏低，且存档预览画风变化微弱 | 底模原本就能以很低误差去噪，LoRA 几乎无需改写权重，对拉动画风作用有限。补充更具目标画风辨识度的训练样本 |

### 不同训练阶段的观察重点

| 训练阶段 | 数据特点 | 观察重点 |
| --- | --- | --- |
| **早期**（`< 3` 个可比较 Epoch，或单图采样 `< 5` 次） | 随机时间步与噪声波动大，尚未算出斜率 | 仅快速扫视最极端的坏图、空标图或 `NaN / Inf`，避免据此大范围删图 |
| **中期**（约 `3 ~ 10` 个 Epoch） | 斜率趋稳，区分度最高 | 重点查看持续高残差且不下降的图片，修正错标、裁剪失误与低画质图 |
| **后期**（长轮数，如 `15+` 个 Epoch） | 全集进入平台期，斜率普遍接近 `0%` | 留意原本接近均值的图片是否明显下沉为低残差，结合预览判断是否早停或回选更早存档 |

### 训练实战注意事项

- **运行中改标注 / 删图不会即时生效**：在开启文本编码器缓存（Anima / MOSS-Image 默认开启）或 Latent 缓存时，运行期间修改 `.txt` 或原图不会作用于当前任务；未开缓存时中途删图还可能中断数据读取。建议边排查边记录或修改，停训后重新开始或重新缓存再验证。
- **数据增强与蒙版权重会放大波动**：开启 `caption_dropout_rate`、`shuffle_caption`、`random_crop`、`color_aug` 会提高单步 Loss 随机性，可适当将**最少采样**调高至 `5` 或 `10` 并多训几轮再判断；开启 `masked_loss` 时，有效蒙版面积差异较大的图片残差也会出现系统性偏移。
- **二维散点图点数可能少于状态卡片统计**：满 3 轮后，二维散点图仅绘制同时满足 `≥ 最少采样` 且已算出斜率的图片；`NaN / Inf`、采样不足及尚未满 3 个可比较 Epoch 的图片可在**逐图排查**中查看。

<a name="workflow"></a>
## 面板区域与联动操作

| 面板区域 | 展示内容与操作方式 |
| --- | --- |
| **顶栏 · 视图与范围控制** | 左侧切换**诊断总览 / 逐图排查**，右侧选择**最少采样**（`1 / 3 / 5 / 10`）、**数据集**范围与**记录段**。存在正则图时默认选**仅训练集**防止拉偏基准，可按需切至**仅正则集 / 全部数据集**；复用输出目录会向同一 `loss.jsonl` 追加新段，**断点续训**选**合并全部记录（N 段）**以跨段计算斜率，**同名重训**保持默认的**最新（ID）** |
| **总览顶部 · 诊断结论条** | 汇总当前状态（如 `NaN / Inf`、高残差统计或分布平稳提示），并提供一键跳转按钮与残差显著偏高的分组标签 |
| **左栏 · 散点图** | 满 3 个可比较 Epoch 前展示一维残差分布，之后切换为**残差 × 斜率**二维散点图。开启右上角**区域着色**后点击右上或右下色区可一键筛选**高残差（不下降）**或**高残差（下降中）**；点击圆点固定预览卡，再点击预览缩略图进入单图详情 |
| **右栏 ① · 图片状态分布** | 汇总 6 类状态图片数；点击任意状态行可联动筛选散点图与时间步曲线 |
| **右栏 ② · 时间步区间（`1000 → 0`）** | 按去噪推进顺序（左高噪 `1000` → 右低噪 `0`）展示 18 个区间的**平均 Loss**、高/中/低噪采样占比与**理论采样**虚线；悬停或选中状态、分组、单图时叠加对比曲线 |
| **右栏 ③ · 分组统计** | 按**数据集子集 / 文件夹 / 分桶尺寸 / 批次大小**汇总平均残差（文件夹与子集重合或维度仅有一组时自动隐藏；**分桶尺寸**长宽比差异达 `4%` 以上会显示**裁剪误差**）。前三个维度支持斜率显示、点击筛选总览及行末 **`↗`** 直达**逐图排查**；**批次大小**仅支持悬停预览，不计算斜率也不可点击跳转 |
| **单图详情弹窗** | 左侧对照 `原图 → 分桶` 尺寸及裁剪百分比 / 放大倍数指示；右侧查看逐轮残差折线、各时间步采样偏离位置与从磁盘读取的**标注文本**（或 `class_tokens`） |

<a name="residual"></a>
## 计算口径与上游差异

本功能读取 `sd-scripts` `--run_control` 写入的 `loss.jsonl`，并在上游 [`tools/analyze_run_loss.py`](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/tools/analyze_run_loss.py) 基础上做了以下增强：

<a name="residual-bins"></a>
### 残差基准（10 等宽区间）

将观测到的时间步范围等分为 10 个区间，同一区间内至少有 **2 张不同图片**才构成有效参照（缺失时间步或独自落入某区间的采样仅计入平均 Loss 与总采样数）：

<div class="doc-equation" role="group" aria-label="单次采样残差公式">
  <div class="doc-equation-kicker">单次采样残差</div>
  <div class="doc-equation-expression">残差 = 单次 Loss ÷ 所在时间步区间平均 Loss − 1</div>
  <p>单图或分组残差为全部可比较采样残差的算术均值（<code>0%</code> 为均值，正值偏难学，负值偏易学）。</p>
</div>

<a name="slope"></a>
### 同轮同区间斜率与跨度阈值

计算逐轮残差时，改以**同一 Epoch、同一时间步区间内其他图片的平均 Loss**（`> 0`）为基准，满 3 个可比较 Epoch 后做最小二乘线性拟合，剥离全局 Loss 自然下降对斜率的干扰。判定**高残差（下降中）**的**下降斜率阈值**按首末可比较 Epoch 的跨度（`span`）分段折算：

| 可比较 Epoch 跨度（`span`） | 下降斜率阈值 | 说明 |
| --- | --- | --- |
| `span ≤ 5`（`≤ 6` 个连续 Epoch） | `-2.0% / Epoch` | 短程训练要求明确的每轮降幅 |
| `5 < span < 25` | `-10% / span` | 按跨度内累计降幅 `≥ 10%` 自动折算 |
| `span ≥ 25` | `-0.4% / Epoch` | 长轮数下限，避免把缓慢稳步收敛误判为停滞 |

<a name="timestep-deweighting"></a>
### 时间步权重还原与日志刷盘

- **时间步权重还原**：`loss.jsonl` 记录的 `loss` 含有 `--weighting_scheme`（见[时间步](timesteps.zh-CN.md#weighting)）和蒙版权重，不含样本 `loss_weight`（如 `--prior_loss_weight`）与 `--min_snr_gamma`。在 **Anima** 与 **MOSS-Image** 下启用 `sigma_sqrt` 或 `cosmap` 时，诊断会先除以对应时间步权重还原未加权 Loss，再统计区间均值与残差。
- **刷盘与多卡限制**：日志约每 5 秒随 `status.json` 同步落盘；多卡训练仅记录主进程（rank 0）抽到的样本。完整字段定义见上游 [`run_control.md#lossjsonl`](https://github.com/kohya-ss/sd-scripts/blob/v0.13.1/docs/run_control.md#lossjsonl)。
