# AdaLN 変調層

<a name="overview"></a>
## 役割・パラメータ増加量・使いどころ

AdaLN（適応型レイヤー正規化）は現在のタイムステップ（ノイズ強度）に応じて各 Transformer ブロック内の特徴スケール・オフセット・残差ゲート強度を動的に変化させ、高ノイズの構図決定段階から低ノイズの細部描写段階までモデルの振る舞いを調整します。

Anima のネイティブネットワークでは既定で除外されています。「AdaLN 層も学習」をオンにすると、既存の Attention・MLP に加えて各メインブロックの 3 系統の変調 Linear 層にアダプタが追加され、パラメータ数と重みサイズが大きく増えます（28 ブロックの Anima-Preview・標準 LoRA・Rank `32`・`bf16` の実測値。40 ブロックの Anima-2.9B では `400 → 640` 層へ比例して増えます）：

| 設定 | 対象 Linear 層数 | 学習可能パラメータ数 | 推定ファイルサイズ（`bf16`） |
| --- | --- | --- | --- |
| オフ（ネイティブ既定） | `280` 層 | `45.88M` | `87.6 MiB` |
| オン | `448` 層（`+168` 層） | `69.27M`（**`+51.0%`**） | `132.3 MiB`（`+44.7 MiB`） |

<div id="effects"></div>
<div id="usage"></div>

- **オフのまま推奨（既定）**：単一キャラクター・顔立ち・衣装・小物、または少数枚（`30` 枚未満）のデータセット。Attention と MLP だけで十分に特徴を再現でき、ファイル肥大化や早い過学習を抑えられます。
- **オンを試す価値がある場面**：画面全体の色調・ライティング・コントラスト階層・独特の空気感など、ノイズ除去の全段階にわたってトーンを変化させたい画風・スタイル学習。
- **効きすぎの症状と比較手順**：オンにした結果、光源の向きや背景の色味が学習画像に張り付いたり、環境や照明に関するプロンプトへの反応が鈍くなったりする場合は、変調層がデータセットの統計を覚え込みすぎています。効果を検証する際は、データセット・Rank・学習率・シード・総ステップ数を固定し、AdaLN スイッチだけを切り替えて同一ステップのチェックポイントを比較してください。

<a name="settings"></a>
## ネイティブネットワークと LyCORIS の対象範囲の違い

<div id="default-behavior"></div>

Anima のネイティブネットワークと LyCORIS プリセットでは、AdaLN の既定の扱いが逆になっているため、モジュール切り替え時は注意してください。

| ネットワーク実装 | 操作箇所 | 既定の対象範囲とスイッチの動作 |
| --- | --- | --- |
| Anima のネイティブネットワーク（`networks.lora_anima`・`networks.loha`・`networks.lokr`） | メインフォームの「AdaLN 層も学習」 | **既定で除外**。オンにすると各ブロックの 3 系統の AdaLN 変調層を追加 |
| LyCORIS（`full`・`full-lin`、または範囲揃えオフの `attn-mlp`） | 追加操作不要 | **既定ですでに AdaLN 変調層を含む** |
| LyCORIS（`attn-mlp` +「sd-scripts の既定範囲に合わせる」がオン） | LyCORIS 設定内の「AdaLN 変調層も学習」 | 範囲揃えをオンにするとネイティブ同様に AdaLN が除外されるため、学習に含めるには内側の AdaLN スイッチをオンにする |

Anima のネイティブネットワークは、既定で `.*(_modulation|_norm|_embedder|final_layer).*` に一致する変調層・正規化層・埋め込み層・出力層（`final_layer`）を除外します。メインフォームのスイッチをオンにすると、`network_args` に次の指定が追加されます。

```text
include_patterns=['.*(adaln_modulation_cross_attn|adaln_modulation_mlp|adaln_modulation_self_attn).*']
```

これにより自己注意・交差注意・MLP の 3 つの変調分岐だけが除外から外されます（「ネットワークの追加引数」に既存の `include_patterns` がある場合は 1 つのリストへ統合されます）。正規化層・埋め込み層・出力層（`final_layer`）は引き続き除外されます。設定変更後は、[行列構造とファイルサイズ](matrix-preview.ja-JP.md)ダイアログで対象レイヤー数と推定サイズを確認してください。
